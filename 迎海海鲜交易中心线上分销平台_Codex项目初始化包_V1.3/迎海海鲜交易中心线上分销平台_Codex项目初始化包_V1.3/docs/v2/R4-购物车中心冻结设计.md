# R4 购物车中心冻结设计

## 目标与边界

R4 只建设购物车能力，不创建订单、不支付、不锁库存、不扣库存。

购物车是用户购买意向暂存区，库存锁定只允许 R5 创建订单时调用 R3 `LockInventory`。

## 数据表

### cart_items

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT UNSIGNED PK | 主键 |
| user_id | CHAR(36) | 当前用户 |
| product_id | BIGINT UNSIGNED | 商品 |
| sku_id | BIGINT UNSIGNED | SKU |
| quantity | INT UNSIGNED | 数量，1-999 |
| selected | TINYINT(1) | 是否选中 |
| created_at | DATETIME(3) | 创建时间 |
| updated_at | DATETIME(3) | 更新时间 |

唯一约束：

`uk_cart_items_user_sku(user_id, sku_id)`

同一用户同一 SKU 重复加入时，不新增第二条记录，而是原子累加数量。

## 数量规则

- `quantity >= 1`
- 单 SKU 上限：`999`
- `quantity=0` 不代表删除，删除必须使用 DELETE API。

## 价格规则

购物车不冻结订单价。购物车返回时实时关联当前 SKU：

- 商品名
- SKU 名
- 主图
- 当前 `salePrice`
- 当前库存状态

`subtotal = Σ(selected=true 且 available=true 的 salePrice × quantity)`

不计算优惠券、运费、税费、积分、会员折扣、分销佣金。

## 商品有效性

每个 cart item 返回：

- `available`
- `unavailableReason`

失效原因：

- `PRODUCT_OFF_SHELF`
- `SKU_DISABLED`
- `OUT_OF_STOCK`
- `INSUFFICIENT_STOCK`

购物车读取不自动修改用户数量。

## 库存关系

R4 只读库存：

- 可以读取 `inventories` 计算 `availableStock`
- 禁止调用 `LockInventory`
- 禁止调用 `UnlockInventory`
- 禁止调用 `DeductInventory`

## API

统一挂载：

`/api/v2/app/cart`

- `GET /api/v2/app/cart`
- `POST /api/v2/app/cart/items`
- `PATCH /api/v2/app/cart/items/:id`
- `PATCH /api/v2/app/cart/items/:id/selected`
- `PATCH /api/v2/app/cart/selection`
- `DELETE /api/v2/app/cart/items/:id`
- `DELETE /api/v2/app/cart/unavailable-items`

所有接口必须基于 `current_user_id` 隔离数据，禁止仅凭 cartItemId 修改。

## 错误码

- `CART_ITEM_NOT_FOUND`
- `CART_QUANTITY_INVALID`
- `CART_QUANTITY_LIMIT_EXCEEDED`
- `CART_ITEM_UNAVAILABLE`
- `PRODUCT_OFF_SHELF`
- `INSUFFICIENT_STOCK`
- 复用 `SKU_NOT_FOUND`、`SKU_DISABLED`
