# 迎海 V2 数据库与 API 总体冻结设计 V2.1

## 1. 技术架构

- 后端：Go + Gin
- ORM：GORM
- 数据库：MySQL 8.4 / InnoDB / utf8mb4
- 缓存：Redis
- API 前缀：`/api/v2`
- 认证：JWT Bearer Token
- 文档：Swagger / OpenAPI

## 2. 当前实现边界

R1 只实现用户与认证系统：

- 微信登录
- JWT 签发与校验
- 当前用户资料
- 用户资料更新
- 地址管理
- 登录记录

R1 不实现：

- 商品
- 购物车
- 订单
- 支付
- 退款
- 分销
- 会员积分
- 后台权限

## 3. 数据库原则

- 所有业务表使用 MySQL InnoDB。
- 主键统一使用 `char(36)` UUID 字符串。
- 时间字段使用 `datetime(3)`。
- 软删除字段统一为 `deleted_at datetime(3) null`。
- 金额字段后续统一使用 `decimal(12,2)`，R1 暂不涉及金额。
- JSON 扩展字段使用 MySQL `json` 类型。

## 4. API原则

- 用户端 API 前缀：`/api/v2/app`
- 后台 API 前缀：`/api/v2/admin`
- 手机后台 API 前缀：`/api/v2/mobile-admin`
- 统一响应：

```json
{
  "code": "OK",
  "message": "success",
  "data": {},
  "requestId": "..."
}
```

- 统一错误：

```json
{
  "code": "UNAUTHORIZED",
  "message": "invalid token",
  "requestId": "..."
}
```

## 5. R1 状态

本文件为 V2.1 在当前仓库的执行版整理，后续数据库 V2 与 API V2 详细设计进入后，以详细设计为准继续扩展。
