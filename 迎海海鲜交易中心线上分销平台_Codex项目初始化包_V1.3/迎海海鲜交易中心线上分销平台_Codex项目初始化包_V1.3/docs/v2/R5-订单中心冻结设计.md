# R5 订单中心冻结设计

## 设计审查结果

- R3 兼容问题：`inventory_transactions` 当前唯一约束为 `reference_type + reference_id + type`，无法支持一个订单多个 SKU 同时产生 `ORDER + order_no + LOCK` 流水。
- 修正方式：通过 R5 新 Migration 删除旧唯一约束，新增 `UNIQUE(sku_id, reference_type, reference_id, type)`，不修改旧 Migration。
- 事务边界：订单创建、订单明细快照、库存 LOCK、库存流水必须在同一个数据库事务中完成；取消/超时关闭与库存 UNLOCK 也在同一事务中完成。
- Inventory Service：R5 允许扩展 `LockInventoryWithTx`、`UnlockInventoryWithTx`，禁止外层订单事务 + 内层库存独立事务。

## 订单状态机

- `PENDING_PAYMENT`：订单已创建，库存已锁定，等待 R6 支付。
- `CANCELLED`：用户主动取消，释放库存。
- `CLOSED`：订单超时关闭，释放库存。
- 未来预留：`PAID`、`PROCESSING`、`SHIPPED`、`COMPLETED`、`REFUNDING`、`REFUNDED`。

允许转换：

- `PENDING_PAYMENT -> CANCELLED`
- `PENDING_PAYMENT -> CLOSED`

禁止恢复关闭订单。

## 幂等设计

- 客户端提交 `requestId`。
- `orders` 增加 `UNIQUE(user_id, request_id)`。
- 同一用户同一 `requestId` 重复创建订单时，返回原订单，不重复创建订单、不重复创建明细、不重复锁库存。

## 订单号方案

- 格式：`YH` + 毫秒时间戳 + 6 位随机数。
- 不暴露数据库自增 ID 作为业务订单号。
- 可用于客服查询与未来支付 reference。

## 商品快照

`order_items` 固化：

- `product_name`
- `sku_name`
- `product_image`
- `unit_price`
- `quantity`
- `subtotal`

商品后续改名、改图、改价不影响历史订单。

## 金额规则

- 金额统一使用人民币分。
- `item_amount = Σ(unit_price × quantity)`
- R5 `discount_amount = 0`
- R5 `shipping_amount = 0`
- `payable_amount = item_amount - discount_amount + shipping_amount`
- 前端金额、商品名、SKU 名、价格均不可信。

## Preview 与价格变化

- `POST /api/v2/app/orders/preview` 只校验商品/SKU/库存/价格，不创建订单、不锁库存。
- Preview 返回 `priceSnapshot`。
- `POST /api/v2/app/orders` 创建时重新读取价格并校验 `priceSnapshot`。
- 价格变化返回 `ORDER_PRICE_CHANGED`，要求用户重新确认。

## 多 SKU 锁库规则

- 多 SKU 下单必须按 `sku_id ASC` 稳定顺序锁库，降低死锁概率。
- 任一 SKU 锁库失败，整个订单事务回滚，不能留下半张订单或库存锁定残留。
- 库存 Reference 统一：
  - `reference_type = ORDER`
  - `reference_id = order_no`
  - 创建订单：`LOCK`
  - 取消/超时关闭：`UNLOCK`
  - 未来支付：`DEDUCT`

## API

- `POST /api/v2/app/orders/preview`
- `POST /api/v2/app/orders`
- `GET /api/v2/app/orders`
- `GET /api/v2/app/orders/:id`
- `POST /api/v2/app/orders/:id/cancel`
- `POST /api/v2/app/orders/expired/close`：R5 简单 Job 入口，占位于服务层能力
- `GET /api/v2/admin/orders`
- `GET /api/v2/admin/orders/:id`

## 明确禁止

R5 不创建支付、退款、售后、分销、佣金、提现、结算等能力；不调用 `DeductInventory`。
