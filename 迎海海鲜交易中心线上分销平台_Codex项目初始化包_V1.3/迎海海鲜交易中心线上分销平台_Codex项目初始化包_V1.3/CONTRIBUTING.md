# 迎海海鲜交易中心线上分销平台贡献规范

本项目采用 Monorepo 工程结构。所有开发任务必须遵循项目设计文档与 Sprint 任务边界。

## 基本原则

1. 不得擅自修改业务流程。
2. 不得擅自修改数据库结构。
3. 不得擅自修改 API 契约。
4. Sprint 0 只允许初始化工程骨架，不允许实现商品、订单、支付、分销、会员等业务功能。
5. 所有变更必须说明影响范围、验证方式和是否涉及数据库/API。

## 开发流程

1. 从受保护分支拉取最新代码。
2. 基于任务创建规范分支。
3. 按任务范围开发。
4. 本地执行必要检查。
5. 提交符合 Commit 规范的提交。
6. 发起合并请求并说明变更内容。
